# java-openai-docs

java-openai 使用文档：统一调用大模型、流式响应、多模态与语音接口。

- 文档站：https://java-openai.io.nexus/
- 项目源码：https://github.com/litongjava/java-openai
- 拆分自 [tio-boot-docs](https://github.com/litongjava/tio-boot-docs)

## 本地开发

```bash
pnpm install
pnpm docs:dev
```

## 构建

```bash
pnpm docs:check
pnpm docs:build
```

构建产物位于 `docs/.vuepress/dist`。
